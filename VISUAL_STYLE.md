# Door Puzzle — визуальный стиль

Ориентир — спокойная минималистичная подача The Chronos Principle.
[Официальный press kit Logisk Studio](https://logisk-studio.web.app/press/the-chronos-principle/index.html)
описывает спокойную атмосферу и светлую/тёмную темы. Door Puzzle использует собственную
геометрию комнат и дверей, типографику и композицию. Ассеты, логотипы и экраны референса
не используются.

## Общая система

Тёплый нейтральный фон, тёмная графичная структура дома, матовые приглушённые акценты.
Общие цвета задаются в `Assets/Scripts/PuzzleVisualStyle.cs`, окружение и текст
каждого уровня — в `Assets/Scripts/PuzzlePalette.cs`.

## Поле

- Стены — простые тёмные линии толщиной 0.085 world units.
- Двери сохраняют ширину 0.6, а толщина уменьшена с 0.16 до 0.09.
- Области нажатия на двери остаются прежними и не зависят от толщины створки.
- EXIT, закрытие дверей, one-way arrows и их минимальный размер сохранены.
- Вместо рамок по углам — одна небольшая точка в центре каждой комнаты до выбора старта.
- Персонаж сохраняет форму и размер, его светлый ободок стал тоньше.
- Тени окружения ослаблены; дополнительных эффектов нет.

## HUD и кнопки

Один стандартный sans-serif Unity (`LegacyRuntime.ttf`, запасной Arial).
Размеры ниже указаны в координатах Canvas 1080×1920 и масштабируются существующим CanvasScaler.

| Элемент | Размер шрифта |
| --- | --- |
| LEVEL | 28 |
| PUZZLE n/4 | 50, bold |
| Doors n/m | 30 |
| CHOOSE START ROOM | 30, normal |
| RESTART / HOME | 30, normal |
| Кнопки результатов / выбора | 34 |
| Заголовки результатов | 60–72 |

LEVEL и PUZZLE имеют одну левую границу. Doors выровнен вправо по той же строке, что PUZZLE.
Под HUD остаётся тонкий разделитель. У Doors и CHOOSE START ROOM нет карточек.
RESTART и HOME — иконка с текстом без подложки; прозрачный Image сохраняет всю область
нажатия. Их текст и иконки становятся светлыми на Level 2.

Прямоугольные action buttons имеют общую высоту 108, одинаковое небольшое скругление
(`ButtonCornerScale = 1.5`) и общую палитру состояний нажатия.
Вторичные действия используют более лёгкий тёплый оттенок.
Кнопка настроек остаётся круглой; кнопки выбора пазла имеют высоту 120 для двух строк текста.
Отступы safe area, зоны поля и логика переходов сохранены.

## Меню и результаты

Main Menu сохраняет композицию: preview board, DOOR PUZZLE, Choose. Cross. Close.,
PLAY, SELECT PUZZLE и настройки. Превью — плоская схема четырёх комнат с общей палитрой.
Убраны объёмная подложка, блики, растения, декоративные точки, ромбы и кривые фона.
Фон — едва заметный тёплый градиент.

Result overlays сохраняют один необходимый непрозрачный контейнер для читаемости поверх
поля. У него нет объёмной тени, а status icon отображается без круглой подложки.
Успех отмечен зелёно-бирюзовой галочкой, проигрыш — приглушённым красным крестом,
надписями YOU LOSE / Path blocked. Основные кнопки остаются одинаковыми по стилю.
Настройки музыки/звука и выбор открытых пазлов также используют общую палитру.

## CARP: проверка по коду

- **Contrast:** тёмная структура на светлых комнатах Level 1; светлый HUD на тёмном фоне Level 2.
  Расчёт контраста основных сплошных цветов: текст Level 1 — 9.14:1, вторичный текст —
  4.52:1; текст Level 2 — 7.83:1, вторичный — 5.53:1; текст primary button — 9.71:1.
  Стрелка one-way на базовом полу Level 2 — 4.77:1.
  Статусы Win/Lose отличаются цветом, формой значка и текстом.
- **Alignment:** единая левая граница заголовков, счётчик справа на общей строке,
  разделитель по ширине HUD; footer buttons симметрично расположены.
- **Repetition:** общие цвета игровых маркеров, sans-serif, скругление,
  высоты action buttons, стиль иконок и состояния нажатия.
- **Proximity:** LEVEL, PUZZLE и Doors сгруппированы сверху; подсказка отделена
  разделителем; нижние действия отделены от поля; статус и действие сгруппированы в overlay.

Это проверка параметров и структуры UI по исходному коду. Play Mode и визуальная проверка
на Android не выполнялись; приведённые коэффициенты не учитывают сглаживание, тени,
оттенок конкретного puzzle и смену цвета при нажатии.

## Архитектура

Существующие Canvas/Panels, safe area, Main Menu и все игровые состояния сохранены.
Изменения относятся к presentation. Генератор, solver, конфиги пазлов, input,
прогресс, звук, движение и логика EXIT не изменены.
Внешние ассеты и новые UI-пакеты не добавлены.

Иконка приложения и её Adaptive Icon настройка в `Assets/Editor/AndroidIconSetup.cs`
остаются прежними.
